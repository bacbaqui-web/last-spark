# LAST SPARK

브라우저용 싱글플레이 3D FPS 생존전 프로토타입입니다.

## 실행

이 폴더에서 `npm install`, `npm run dev`를 실행한 뒤 표시된 localhost 주소를 여세요. 현재 실행 주소는 http://127.0.0.1:5173 입니다. Chrome 등 마우스 고정을 지원하는 데스크톱 브라우저를 권장합니다.

## 조작

- WASD: 이동 / Shift: 질주
- 마우스: 조준 / 왼쪽 버튼: 사격 (누르고 있으면 연속 사격)
- Space: 점프, 공중에서 다시 누르면 이단 점프
- Tab: 1인칭 ↔ 3인칭 전환
- Esc: 일시정지
- 마우스 고정을 지원하지 않는 브라우저: 마우스 이동으로 조준, 오른쪽 버튼 드래그도 지원

## 규칙

기본 딱총은 탄약이 무한입니다. 적 처치 시 확률적으로 기관총(100발), 산탄총(24발), 전자포(16발)가 떨어집니다. 두 번째 처치는 반드시 무기를 떨어뜨립니다. 가까이 가면 자동 획득하며, 기존 특수 무기를 교체합니다. 탄약을 모두 쓰면 딱총으로 돌아옵니다. 드롭은 35초 뒤 사라집니다.

45초마다 보스가 등장하며 시간이 지날수록 적이 더 자주 나타나고 강해집니다. 일부 처치와 보스 처치는 생명력을 회복합니다. 체력이 0이 되면 생존 시간과 처치 수를 보여주며 다시 도전할 수 있습니다.

3D 적과 지형은 단순한 형태로 제작했습니다. 총성, 반동, 명중음, 약점 추가 피해, 피격 반응, 처치 파편을 적용했습니다. 밸런스와 손맛은 실제 플레이 피드백을 받아 조정해야 합니다.

## 검증

Vite production build 통과. 로직 검증: 사격 명중, 처치, 무기 획득, 탄약 소진 복귀, 보스 등장 주기, 발판 착지, 게임 오버 및 재시작. 앱 브라우저에서 렌더링·시작·사격 입력·게임 오버 화면 확인; 실행 오류 없음. 장시간 생존 밸런스 및 일반 브라우저 마우스 고정은 별도 플레이 확인이 필요합니다.

## 첫 플레이 피드백 반영

적 색상과 발광 보정으로 몸통 식별을 개선하고, 적이 플레이어에게 과도하게 밀착하지 않도록 정지 거리를 늘렸습니다. 초기 적은 정면에서 시작합니다. 일반 적 초기 체력 36(딱총 몸통 2발 / 머리 1발), 속도 1.8, 공격 피해 4, 공격 간격 1.5초로 완화했습니다. 적 생성 간격은 처음 2.8초이며 최대 적 수는 26입니다. 피격 후 0.65초간 추가 피해를 막아 여러 적의 동시 공격 피해를 제한했습니다. 보스 체력과 피해도 줄였습니다.

앱 브라우저에서 실제 우클릭 드래그 전후 시선 각도 변화를 확인했습니다. 일반 마우스 이동 조준과 실제 처치를 확인했고, 원거리 및 근거리에서 머리와 몸통 표시를 확인했습니다. 빌드 및 로직 검사는 통과했습니다.

## 군중 표시 점검

일반 적 생성은 살아 있는 적 수 26에서 멈추며 보스는 별도로 생성됩니다. 수량을 기준으로 적의 몸을 숨기는 렌더링 제한은 없습니다. 개발용 검사 장면에서 26마리 / 182개 신체 메시가 함께 표시되는 것을 확인했습니다. 군중이 한 자리에 겹치지 않도록 수평 분리 처리를 추가하고, 새 적이 플랫폼 내부에서 생성되는 경우를 줄였습니다. 실제 사용자 환경의 원래 소실 현상은 정확히 재현되지 않아 원인을 확정하지 않았습니다.

## 감도와 질주, 점프

[ 키는 마우스 감도를 0.1씩 낮추고 ] 키는 0.1씩 높입니다. 범위는 0.3~3.0배이며 화면에 현재 감도가 표시됩니다. 질주 속도는 18(기본 이동 8.2)로 올렸고, 질주하면서 이동할 때 좌우 카메라·무기 흔들림, 약한 확대(FOV 78→73), 가장자리 블러를 적용했습니다. 멈추면 효과가 부드럽게 사라집니다. 첫 점프 초기 속도는 9→13, 이단 점프는 8.4→12.2로 올렸습니다. 첫 점프 높이는 약 1.76→3.67입니다.

감도 증가·감소, 질주 속도·확대·블러 및 효과 복귀, 점프 높이 검사 통과. 실제 브라우저에서 ] 키 감도 표시 1.0→1.1, 질주 시 속도·FOV 변화, 가장자리 블러 지원 및 적용을 확인했습니다.

## 관절 로봇과 행동 AI

네모 로봇을 어깨·팔꿈치·골반·무릎 관절로 나누고 별도 총을 손에 연결했습니다. 실제 이동량에 맞춰 걷고, 멈춰 팔을 들어 조준한 뒤 총구에서 붉은 공을 발사합니다. 발사 후 옆으로 이동하고 다시 접근합니다. 일반 적은 약 0.9초, 보스는 약 1.1초 조준 후 사격합니다. 장애물이 가리면 사격하지 않으며, 피격되면 잠시 멈추고 공격 준비를 취소합니다. 처치 시 몸이 기울고 무릎이 꺾이는 쓰러짐 동작을 보여줍니다.

행동 상태 전환에는 MIT 라이선스 Yuka의 StateMachine을 실제 사용합니다. 관절 모델과 애니메이션은 이 게임에 맞춰 직접 작성했습니다. Dive 코드는 가져오지 않았으며, Recast 경로 탐색은 아직 적용하지 않았습니다. 현재 이동은 기존 장애물 우회와 군중 분리 방식입니다. Yuka 라이선스는 public/YUKA-LICENSE.txt에 포함했습니다.

검증: 관절 걷기·조준·반동·쓰러짐, AI 접근→조준→사격→재이동 및 피격 중단 검사 통과. 기존 사격·획득·탄약 소진·보스·점프·질주 회귀 검사 통과. 브라우저에서 모델과 실제 상태별 팔 자세, 사격 후 정상 몸 표시를 확인했습니다.

### 적 동작 개선
Yuka Vehicle + ArriveBehavior로 이동 속도를 적분하며 약 0.2초 단위로 가속·감속합니다. 벽 접근 시 방향을 미리 조정하고, 실제 이동 거리와 방향에 맞춰 전진·후진·옆걸음 관절을 혼합합니다. 상체 기울기, 조준, 피격도 보간합니다. 전술 엄폐 선택은 아직 별도 구현이 필요합니다.

### 실제 뼈대 애니메이션 (2026-10-01)
네모 체형을 얇게 변경하고 Quaternius Universal Animation Library Standard의 65 Bone 뼈대에 갑옷 조각을 rigid binding했습니다. 기존 사인파 관절 동작을 Three.js AnimationMixer의 실제 클립 재생으로 교체했습니다. 대기/걷기/조깅/질주를 속도로 혼합하고, 상체 권총 조준(상/중/하)·사격·피격과 하체 이동을 분리합니다. 사망은 Death01 클립을 재생합니다. 크기 보정은 캐릭터 높이 2m대 유지용이며, 각 적의 뼈대·믹서는 독립적입니다.

원본: https://quaternius.com/packs/universalanimationlibrary.html (CC0). 배포 라이선스는 public/QUATERNIUS-LICENSE.txt. rig-data.json은 무료 Standard GLB에서 필요한 13개 클립과 뼈대를 추출한 데이터이며, 원본 사람 메시와 손가락 동작은 포함하지 않습니다. Crouch 동작은 자료에 포함됐지만 전술 엄폐 AI는 아직 연결되지 않았습니다.
검증: 빌드, 실제 Bone/무릎 quaternion 변화/조준 총구 전방/키와 약점 검사, 기존 전투·질주·점프 회귀 검사 통과. 브라우저에서 체형과 실제 클립 렌더링 확인.

### 전투 기동과 시선 반응 AI
기본 마우스 감도 2.0배([/] 조절 유지). 플레이어 걷기 9.8, 질주 22. 일반 적 기본 이동 3.2, 보스 2.5. 적 투사체 속도 일반 22/보스 25이며 선분 충돌로 빠른 탄환이 플레이어·벽을 건너뛰지 않게 합니다. 플레이어 총은 기존 즉시 명중 판정입니다.
Q/E는 시야 기준 좌우, X는 뒤쪽으로 0.18초간 속도 30 회피(공유 쿨다운 0.7초). 무적은 부여하지 않습니다. C 근접은 앞쪽 거리 3.4에서 한 적에게 48 피해(쿨다운 0.5초), 벽에 가려진 대상은 제외합니다.
적을 시야 중심 약 10도 안에 1.3~1.95초간 두면 반응합니다. 높이·시야 차단·20m 이내 도달 가능한 엄폐 지점을 찾고, 확장된 벽 모서리 그래프의 최단 경로로 이동해 1.3초간 숨은 뒤 전투에 복귀합니다. 지점이 없거나 보스인 경우 좌우 회피합니다. 반응 쿨다운 3.5초 이상, 이동 제한 5초로 한 행동에 묶이는 것을 방지합니다.
검증: 전투 회귀 + 회피 방향/쿨다운, 근접 피해/쿨다운, 시선 반응/엄폐 복귀, 벽을 가로지르지 않는 엄폐 경로, 빠른 탄환 선분 충돌 통과.

### 구르기·수류탄·광자포
Q/E/X는 0.36초간 좌우/뒤로 구릅니다. 카메라를 낮추고 방향에 따라 한 바퀴 회전하며, 끝나면 원래 시점으로 복귀합니다. 쿨다운 0.85초, 구르는 동안 사격·근접·수류탄은 제한됩니다.
Z 수류탄: 4초 쿨다운, 중력 포물선과 벽/바닥 반사, 1.6초 신관(적에 닿으면 즉시 폭발), 반경 6·중심 피해 125. HUD에 준비/남은 시간을 표시합니다.
기존 전자포 드롭을 광자포로 변경: 보라색 구체 속도 28, 16발, 적/벽 접촉 시 반경 4.8·중심 피해 110 폭발. 탄약 소진 시 딱총으로 복귀합니다. 두 폭발 모두 거리에 따라 피해가 줄고 엄폐물에 막히며 플레이어 자해는 없습니다. 투사체는 선분 충돌을 사용합니다.
검증: 기존 회귀 + 구르기 시점/복귀, 광자탄 생성·접촉·다중 적 피해·탄약 복귀, 수류탄 키/쿨다운/궤적/신관, 폭발 벽 차단, 재시작 투사체/효과 정리 통과.

### 회피 대상 수정 및 적 달리기·제동
구르기는 적 행동입니다. 플레이어 Q/E/X는 시점이 회전하지 않는 기존 빠른 회피(0.18초, 쿨다운 0.7초)로 복구했습니다. 적 Dodge 상태에 CC0 Standard 팩의 실제 Roll 클립을 추가해 0.72초 동안 이동 방향을 향해 구릅니다. 해당 동작 중 상·하체 일반 동작을 줄이고, 종료하면 달리기로 혼합합니다.
일반 적 접근 속도는 5.2(시간에 따라 6.5까지), 보스 3.6입니다. 실제 이동 속도에 따라 Jog/Sprint 가중치와 재생 속도를 조절합니다. 정지 명령 때 이동 감쇠를 약 0.36초로 늘려 짧은 관성 이동을 만들고, 감속 크기에 따라 걸음을 멈추며 무릎 굽힘·뒤로 기울기 제동 자세를 더합니다. 전용 Stop 원본 클립은 무료 팩에 없어 기존 클립 혼합과 추가 관절 보정으로 구현했습니다.
검증: 적 실제 Roll 재생/몸 낮춤/달리기 복귀, 제동 자세와 원상 복귀, 플레이어 시점 수평 유지, 기존 전투·폭발·AI 회귀 통과.

### 엄폐물·웨이브·거대검 TPS
엄폐물 14개 추가(총 22개 플랫폼/장애물). 접근 AI도 벽 모서리를 돌아가는 경로를 사용합니다. 실시간 추가 스폰/45초 보스 타이머를 제거했습니다. 시작부터 보스 1마리 + 일반 적 7마리, 웨이브마다 일반 적 2마리 증가(최대 24). 모든 적을 처치하면 체력 20 회복 후 3초 뒤 다음 보스 웨이브로 진행합니다. HUD에 웨이브와 남은 적을 표시합니다.
검은 랜덤 드롭에 포함하며 2번째 처치에서 검 드롭을 보장합니다. 보스 보상은 검과 광자포를 번갈아 제공합니다. 획득하면 TPS로 전환, 플레이어의 얇은 리깅 캐릭터와 2.7m 거대검을 보여줍니다. CC0 Sword_Idle/Sword_Attack 클립을 상체에 적용하고 하체 이동을 혼합합니다. 좌클릭은 0.55초마다 넓은 앞쪽 반경 5.3의 적들에게 95 피해, 벽 뒤 대상 제외. 24회 사용 후 딱총/FPS 복귀(마지막 휘두르기가 끝난 뒤 전환). 다른 총을 주워도 FPS로 전환합니다. TPS 카메라는 장애물에 막히면 앞으로 당겨집니다.

효과는 같은 생존 중 누적되며, 새로운 게임에서는 초기화합니다. 비율 효과는 곱연산, 자동 수복은 회복률 합산입니다. 적 체력 증가 시 남은 체력 비율을 보존하고, 플레이어 최대 체력 증가 시 증가량만큼 즉시 회복합니다. 선택 화면에 양쪽 누적 능력치를 표시합니다.
