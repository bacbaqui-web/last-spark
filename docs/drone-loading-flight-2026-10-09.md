# 회수작전 출격 비행

회수작전 출격 버튼을 누르면 도시 생성 중 회수 드론에 원격 기체가 탑승한 비행 장면을 표시한다. 기체 통신 연결 → 도시 구역 준비 → 착륙 지점 확인을 거쳐 기존 3.4초 하강 장면과 전투로 이어진다. 로딩 완료 후 연출을 위한 추가 대기 시간은 없다.

- 실제 회수 드론 모델과 현재 기체의 외장·장착 모듈 외형을 사용한다. 전투용 무기 효과·벨트 등의 상태가 유입되지 않도록 임시 기체에서 정적 외형만 복사한다. 비행용 기체 재질은 단순화한다.
- OffscreenCanvas worker에서 30fps로 비행을 렌더링한다. 도시 생성·충돌 준비가 메인 스레드를 점유해도 비행을 갱신할 수 있다. 미지원 환경이나 worker 실패 시 같은 장면을 메인 스레드에서 렌더링한다. 이 경우 동기 지도 생성 구간에서는 애니메이션이 끊길 수 있다.
- 배경은 3개 배치, 총 288개 단순 건물과 64×64 공용 외벽 텍스처를 반복 사용한다. 실제 임무 도시를 추가 생성하지 않는다. 캔버스는 최대 1280×800, 그림자는 사용하지 않는다.
- 출격 저장은 기존처럼 지도 생성 성공 후에 실행한다. 실패 시 임시 화면과 worker를 제거하고 브리핑에서 재시도할 수 있다. 비행 종료 후 worker와 fallback 렌더러, 리스너, 타이머를 정리한다.

## 검증

- 전체 `npm test`: 73/73 통과.
- `scripts/verify-deployment-flight.mjs`: 커스텀·인스턴스 지오메트리의 위치, 숨긴 모델 제외, 원본 리소스 보존, 120초 비행 중 개체 수 고정, 임시 리소스 정리.
- `scripts/check-deployment-flight-browser.mjs`: 별도 Chrome 프로필에서 메인 스레드 1.5초 정지 중 worker 48프레임 진행, 화면 크기 변경, worker 미지원 fallback, 지도 생성 실패·재시도, 저장 데이터 보존, 실제 착륙·적 생성, 종료 후 worker 0개. 브라우저 오류 0개.
- 비행 검증은 전투 FPS 향상 수치를 의미하지 않는다. 비행은 로딩 중에만 실행한다.

브라우저 검증은 개발 서버를 5191 포트로 실행하고 `PLAYWRIGHT_MODULE`에 설치된 Playwright 모듈 경로를 지정해 실행한다. 검증 전용 실패는 브라우저 요청 가로채기로만 주입하며 출시 코드에는 포함하지 않는다. 결과·스크린샷은 `output/drone-flight/`에 저장한다.
