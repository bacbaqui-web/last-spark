# 새 야생 로봇 게임 연결

- 일반 적: 철갑 콩벌레, 용재 포격벌레를 훈련 웨이브와 회수 출격에 추가.
- 보스: 포격 딱정벌레, 여왕말벌, 이끼 사신으로 기존 3종 교체.
- 콩벌레: 예고 중 방향 고정, 충돌까지 직선 구르기, 플레이어 접촉 피해 20 및 넉백, 충돌 뒤 배 노출 2.4초에만 피해 허용, 점프하며 자세 복귀. 중앙 다리와 분절 몸체 유지.
- 포격벌레: 곡사 불덩이 3연발, 착탄 후 5초 지면 화염, 중첩되지 않는 주기 피해.
- 여왕말벌: 복부 6개 발사구에서 0.24초 간격 미사일 발사.
- 이끼 사신: 좌우 교대 대각선 베기, 0.27초와 0.72초에 독립 타격 판정.
- 메쉬/텍스처는 기존 런타임 로딩과 파괴·정리 경로를 사용. 콩벌레는 관절별 재질 배칭과 파괴 파츠 수 제한 적용.

검증: verify-pillbug-combat, verify-pillbug, verify-slag-mortar, verify-wild-bosses, verify-wild-enemy-game, verify-frame-work. 공개 배포는 GitHub Pages 워크플로로 진행.
