# 걷기 기본 / Shift 달리기 / 적 밀도 재조정

사용자 추가 요청: 이동이 여전히 빠르고 적이 적음. 걷기를 기본값으로 바꾸고 Shift를 누르는 동안만 더 느린 달리기를 적용했습니다.

## 변경

- 기본 이동 값: 걷기 2.4m/s, Shift 달리기 4.2m/s, 정밀 조준 2m/s. 일반 출격의 ×0.85 보정을 적용하면 각각 2.04 / 3.57 / 1.7m/s입니다. 장비 이동 보정은 유지합니다.
- 직전 기본 이동 5.78m/s 대비 걷기는 약 65%, 달리기도 약 38% 느립니다. Shift를 놓으면 걷기로 감속합니다. 양쪽 Shift를 지원하며 조준 중에는 달리기보다 조준 속도가 우선합니다.
- 기존 대시와 칼 돌진베기를 E키로 옮겼습니다. 장비 조건·에너지·쿨다운은 유지했습니다. 화면 조작 안내와 무기 설명도 변경했습니다.
- 3인칭은 기본 이동에 TPSWalk, Shift 달리기에 Sprint_Loop를 사용합니다. 걷기 보폭의 재생 속도도 별도로 맞췄습니다.
- 첫 그룹은 6마리, 이후 약 38m마다 최소 4마리. 시작점에서 최소 18m 안전거리와 충돌 검사를 유지합니다. 335m 검증 맵의 총 적은 10 → 35마리(일반 34 + 수호 개체 1)입니다. 먼 적·전리품의 기존 갱신 제한은 유지합니다.
- 짧은 렌더링 지연에도 전투가 일시정지되던 기준을 250ms → 2초로 조정했습니다. 250ms를 넘는 프레임의 누적 시간은 여전히 시뮬레이션하지 않으므로 이동·피해가 한꺼번에 적용되지 않습니다. 창 전환·포커스 이탈의 일시정지는 유지합니다.

## 검증

- 실제 브라우저, 메모리 전용 workshopCheck 캠페인, STAGE 1 / 시드 3040804531: 총 35마리 생성 확인. 가까운 6마리의 수평 거리 19.3 / 23.7 / 24.8 / 28.6 / 32.3 / 32.4m. 충돌 없는 후보 위치로 분산 배치됐습니다.
- 실제 입력 경로 자동 검사: 기본 걷기, 왼쪽/오른쪽 Shift, 한쪽만 놓았을 때 달리기 유지, 모두 놓았을 때 걷기 복귀, 조준 우선, Shift가 대시를 유발하지 않음, E 칼 돌진 통과.
- 걷기/달리기 동작·방향 전환, 적 배치 계획, 기존 개체 자원 해제 검사 통과.
- 전체 검사 최초 실행은 입력 검사 픽스처가 장애물과 추가 웨이브를 만나 56/57이었습니다. 게임 코드를 우회하지 않고 해당 입력 검사의 환경을 격리한 뒤 재실행하여 최종 57/57 통과했습니다(`tests-final.json`, 재검사 표시 포함).
- 추가 프레임 지연 회귀 검사: 350ms 지연은 시간 진행 없이 전투 유지, 2.1초 지연은 시간 진행 없이 일시정지함을 확인했습니다.
- 브라우저에서 기본 걷기 속도 2.0399m/s를 측정했습니다. Shift 양쪽 유지·해제와 달리기 속도는 실제 게임 입력 경로의 자동 검사로 검증했습니다. 브라우저 측정 중 무거운 자동 검사를 함께 실행했으므로 이 결과를 안정적인 FPS 측정으로 사용하지 않습니다.
- 최종 빌드 및 배포 산출물 검사 통과: 283파일 / 144.077MiB. 번들에 최종 2초 일시정지 기준이 포함됐음을 확인했습니다. 큰 JavaScript 청크 경고는 남아 있습니다.
- 원본 로그 및 브라우저 상태는 `output/walk-density/`에 보관합니다. 로컬 수정이며 원격 배포는 수행하지 않았습니다.
