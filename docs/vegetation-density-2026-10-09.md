# 풀·덩굴의 거리별 밀도 조절

## 적용

- 근거리의 원본 삼각형·색상·UV·노멀·배치·그림자 설정을 유지합니다. 이끼 표면 셰이더는 이 변경에 포함하지 않습니다.
- 카메라에서 식물 구역의 경계까지 18m부터 중간 밀도, 40m부터 원거리 밀도를 사용합니다. 돌아올 때는 2m의 여유를 두어 경계에서 반복 전환하지 않습니다.
- 일반 풀 한 포기의 24개 풀잎을 중거리 8개, 원거리 2개로 줄입니다. 잎 카드는 두 삼각형을 항상 함께 선택합니다.
- 덩굴은 같은 가닥의 줄기 전체를 선택하고 잎도 그 가닥에 맞춰 줄입니다. 기존 줄기의 좌표를 연결해 새 모양을 만들지 않아 벽을 뚫는 긴 지름길이 생기지 않습니다.
- 잎·풀은 12m 구역별로 조절하고 가는 줄기는 도로의 각 방향별로 크게 묶습니다. 교차로·커브의 풀과 폐허 건물 덩굴에도 적용합니다.
- 기존 식물 숨김 거리(풀 70m, 일반 잎·덩굴 110m)를 유지하되 구역 중심 대신 경계에서 거리를 계산합니다. 나무의 기존 모델 LOD와 건물·충돌은 유지합니다.
- 한 벌의 정점·인덱스 버퍼에서 그릴 범위만 변경합니다. 매 프레임 모델 생성이나 버퍼 재전송이 없고, 먼 구역의 GPU 자원을 해제했다가 돌아오는 동작도 유지됩니다.

## 삼각형 수

시드 3040804531의 72m 직선도로 한 구역에서 생성되는 풀·덩굴의 단계별 수입니다. 화면의 총 삼각형이나 FPS 향상률과는 구분합니다.

| 요소 | 근거리 | 중거리 | 원거리 | 원거리 감소 |
|---|---:|---:|---:|---:|
| 풀 | 40,128 | 13,376 | 3,344 | 91.7% |
| 덩굴·바닥 잎 | 8,708 | 3,622 | 912 | 89.5% |
| 덩굴 줄기 | 5,930 | 2,960 | 1,480 | 75.0% |
| 전체 | 54,766 | 19,958 | 5,736 | 89.5% |

덩굴 줄기와 잎을 합치면 14,638 → 2,392개로 83.7% 감소합니다. 근거리 물체가 화면 대부분을 차지할 때는 원거리 모델 표의 감소율만큼 화면 전체가 줄지는 않습니다.

## 검증

- `verify-vegetation-density.mjs`: 거리 복귀·경계 여유, 24/8/2 풀잎, 온전한 잎 카드·가닥 선택, 숨겨진 구역, 동결된 좌표, GPU 자원 해제·복귀, 거리 전환 시 버퍼가 변경되지 않는 조건을 검사합니다.
- 기존 건물·나무 LOD 및 정적 묶음 검사도 통과했습니다.
- 변경 전 소스와 직선·커브·T자·막다른 길의 근거리 삼각형을 비교했습니다. 전체 삼각형의 정점·색상·UV·노멀·월드 좌표·그림자 설정이 모두 동일했습니다.
- 브라우저 검증은 별도 Chrome 프로필과 메모리 캠페인으로 실행합니다. 사용자 저장 데이터는 사용하지 않습니다.
- 전체 자동 검사 72/72, 최종 밀도·근거리 원본 비교 검사, 빌드 및 릴리스 파일 검사를 통과했습니다.

## 실제 맵 렌더 비교

회수작전 시드 3040804531, 1280×720, DPR 1, 균형 화질의 동일한 네 카메라 위치입니다. 기존 건물·나무 LOD가 이미 적용된 버전을 기준으로 비교했습니다. 적을 제거한 장면의 렌더러 수치이며 FPS 벤치마크가 아닙니다.

| 경로 위치 | 변경 전 삼각형 | 변경 후 삼각형 | 추가 감소 | 그리기 요청 전 → 후 |
|---|---:|---:|---:|---:|
| 시작점 | 479,077 | 440,118 | 8.1% | 430 → 440 |
| 25% | 667,931 | 582,630 | 12.8% | 447 → 450 |
| 50% | 653,937 | 567,138 | 13.3% | 474 → 476 |
| 80% | 685,239 | 677,515 | 1.1% | 376 → 379 |

근거리 원본 유지 때문에 장면별 효과가 다릅니다. 줄기는 크게 묶어 추가 그리기 요청을 줄였으며, 최종 비교에서 요청 수 증가는 0.4~2.3%였습니다. 전후 브라우저 실행 모두 런타임 오류가 없었고 일시정지·재개 및 모바일 FPS 표시 검사도 통과했습니다.

원시 검사·비교 자료는 `output/vegetation-lod/`, 브라우저 결과는 `output/crowd-performance/summary-vegetation-*.json`에 보관합니다.
