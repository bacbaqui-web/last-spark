# 철갑 콩벌레 동작 시연

독립 시연 pillbug-lab.html과 실제 게임의 웨이브·출격 편성에 연결했습니다. pillbug-combat.js가 예고, 직선 돌진, 플레이어/벽 충돌, 반동, 배 노출, 점프 복귀를 관리합니다. 공유 피해 함수가 무적을 확인하며, 충돌 넉백은 플레이어의 지형 충돌 이동을 사용합니다.
6개 가시 등판, 다리 6개. 붉은 경로 예고 → 도약 변형 → 회전 충전 → 충돌까지 직선 돌진.
플레이어/벽 충돌을 선택할 수 있습니다. 충돌 지점에서 뒤로 튕기며 뒤집힙니다.
평상시·변형·충전·돌진·충돌 반동·회복은 무적. 배를 드러낸 2.4초의 발버둥 구간에만 취약합니다.
플레이어 충돌 시 표적 피해 20과 넉백 시연. 벽 충돌은 플레이어 피해 없음.
검증: node scripts/verify-pillbug.mjs — 두 충돌 경로, 무충돌 지속 이동, 반동, 취약 구간, 자세 회복.

모델 디자인: 3번 이끼·녹슨 폐철갑 컨셉의 수리 장갑과 이끼를 반영하고, 발은 2번의 뾰족한 쐐기형으로 변경했습니다. 등판은 6개 유지. 다리 6개는 옆구리 대신 배의 가로·세로 정중앙 공통 허브에 연결하며, 여섯 방향으로 뻗고 뒤집힌 상태에서 독립적으로 발버둥칩니다. 구를 때는 중앙으로 접혀 숨습니다. 중앙 연결점과 독립 관절 움직임을 검증합니다.

내부 검은 몸체는 머리·가슴·배 세 덩어리와 좁은 연결 관절로 구분. 머리를 앞 등껍질 아래로 후퇴시키고, 등판 폭은 앞뒤가 좁고 중앙이 넓게 조정했습니다. 구를 때는 폭을 균일하게 모아 공 형태를 유지합니다.

보행은 교대 삼각 지지(다리 3개씩)와 발끝 목표 기반 2관절 계산으로 수정. 지지 구간은 이동 속도에 맞춰 발끝을 지면에 유지하고, 유각 구간은 들어서 앞으로 옮깁니다. 정지 중에는 헛걸음을 멈춥니다. 뒤집힌 상태에서 0.18초 준비 → 0.58초 점프와 반 바퀴 회전 → 0.22초 착지 압축으로 복귀합니다.
